## 2. Create the special profile repository
1. Sign in to GitHub.
2. Create a **public** repository whose name is exactly your GitHub username.
3. Add `README.md` (or upload the files from this package).
4. Keep the `assets` folder in the repository; the README uses the SVG files inside it.
5. Commit the changes.

GitHub displays the README from this special repository on your profile page.

## 4. Make it credible and distinctive
- Pin your strongest 3–6 repositories on your GitHub profile.
- Add a useful README to every project: problem, data source, methods, results, limitations, and how to run it.
- Include screenshots or a small sample output where appropriate.
- Do not add skill badges for tools you cannot confidently discuss.
- Keep the project descriptions honest and replace example links with real links.

The visual identity and wording in this starter pack are custom-written for this profile. No one can guarantee that no other profile uses similar design ideas or phrases, but this package is not copied from a specific existing GitHub profile.
