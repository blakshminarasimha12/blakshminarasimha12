## `04 / HOW I APPROACH A PROBLEM`

```text
QUESTION
   ↓
Understand the goal and define success
   ↓
INSPECT
   ↓
Check data quality, missing values, and patterns
   ↓
BUILD
   ↓
Create a baseline analysis or model
   ↓
VALIDATE
   ↓
Test assumptions and measure performance
   ↓
COMMUNICATE
   ↓
Explain the result, limits, and next action
```

I aim to make my work reproducible and understandable—not just make a notebook that runs once.
